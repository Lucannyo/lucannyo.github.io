# Configuração dos agentes

As instruções gerais ficam em `../AGENTS.md`.

- `skills/pandemonivm/SKILL.md`: habilidade local para mudanças na simulação e na entrega.
- `scripts/check.sh`: verificações reproduzíveis com Node.js, Python 3 e Git.

Execute `sh .agents/scripts/check.sh` a partir de qualquer diretório. Não há instalação de pacotes nem dependência de diretórios pessoais. Produto e identidade visual continuam documentados na raiz, sem cópias aqui.
